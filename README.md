# 🎮 LumiaStudio - Game Development Portfolio

Welcome to the official **LumiaStudio** web games portfolio repository!

This repository contains the interactive portfolio showcase along with 6 fully playable, lightweight, standalone web games.

---

## 🕹️ Included Games

1. **Demolition Derby: Crash Arena 3D** (`/derby-destruction-3d/`) - 3D rigid-body vehicle crash physics, car customization garage, arenas & car soccer mode.
2. **Remix Tribal Wars: Merge** (`/remix-tribal-wars_-merge/`) - Chibi tactical card merge and precision slingshot combat.
3. **Star Sector: Void Raiders** (`/star-sector_-void-raiders/`) - Arcade sci-fi space shooter with custom synthesized audio and procedural waves.
4. **Topdown Survivor: Zombie Maze** (`/topdown-survivor_-zombie-maze-strategy/`) - Tactical horror stealth survival with 45 levels and real-time path-drawing mechanics.
5. **TRAPECAVE - Tricky Caves Gravity** (`/trapecave---crazygames/`) - Precision rage platformer featuring 100 troll levels with inverted gravity mechanics.
6. **Trench War WWI** (`/trench-war-wwi/`) - Retro 8-bit military defense and trench warfare conquest.

## 🚀 How to Run Locally

### Option 1: 1-Click Launcher (Windows)
Double-click `START_PORTFOLIO.bat` in the root directory. It starts a lightweight local web server and opens `http://localhost:8080` in your browser.

### Option 2: Using Node.js
```bash
node server.js
```

### Option 3: Using Python
```bash
python -m http.server 8080
```

## 🌐 Free Hosting on GitHub Pages

1. Push this repository to GitHub.
2. Go to your repository **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your games portfolio will be live online with free HTTPS!
